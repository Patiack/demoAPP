# 安心 · 长辈防诈助手

> 先别转，让我帮您看看。

一个不用登录、不联网、数据只留在本机的防诈 Web App。
面向长辈，也面向每一个在电话那头被催着转账的人。

---

## 为什么做这个

针对老年人的骗局，真正的危险往往不是“不知道有诈骗”，而是**在转账前的那三分钟里，身边没有人可以商量**。

常见防诈产品停在“知识科普”：看完文章，真接到电话还是慌。安心把干预放在更靠前的位置：

1. **先看**——把可疑短信、微信话术粘进来，先做一次风险初筛；
2. **先停**——用三分钟冷静倒计时和三个问题，把人从对方的节奏里拉出来；
3. **先问**——一键打给家人或 96110，把“我自己扛”变成“有人陪我”。

它不追求替代警察、银行或家人，只希望在关键时刻多一道缓冲。

---

## 四个功能

### 1. 查一查

- 粘贴或口述一段可疑消息，本地规则引擎给出**高 / 中 / 低**风险判断；
- 按“冒充身份、钱、施压、诱惑、链接、熟人”分组解释可疑点；
- 提取消息里的链接域名，提醒不要点开；
- 识别“反向提醒”：如果这段文字本身是在宣传防骗，不会误当成诈骗话术；
- 识别正常的**验证码短信**，不会把银行发来的验证码误判成“索要验证码”；
- 结果可直接拨打 96110、打给家人，或生成一段求助文字发给家人。

内置 5 个演示样例，首页点“试试”即可。

### 2. 冷静角

- 选择“对方说他是谁”，启动 **3 分钟**倒计时；
- 回答三个问题：是否让你保密、是否让你转“安全账户”或共享屏幕、是否还没告诉家里人；
- 出现危险答案时，提示区直接给出**打给家人**的按钮，不用往下找；
- 倒计时结束后，引导拨打 96110 或让家人陪同去银行；
- 计时状态会保存在本机，切走再回来不会重置。

### 3. 学一学

- 每天 3 道防诈小测，题目按日期固定，连续学习会累计天数；
- 答完立即讲解，答错也能看到正确答案；
- 9 个真实感案例，可按骗局类型筛选；
- 开启“朗读”后，可以听案例（使用浏览器语音合成）；
- 字体放大后依然适配，适合长辈阅读。

### 4. 守护

- 保存家人电话，一键拨打；
- 设置只有家里人知道的**家庭暗号**，用来识破 AI 换脸、克隆声音；
- 一键生成求助消息，可复制、系统分享或直接打给家人；
- 三档字号（标准 / 大 / 特大）、朗读开关；
- 查看本机数据说明，一键清除全部记录。

## 怎么运行

**最简单：双击 `index.html`，用 Edge 或 Chrome 打开。**

不需要安装、不需要构建、不需要联网登录。页面使用普通 `<script>` 标签，`file://` 下也能完整运行。

带演示样例的地址（在浏览器地址栏打开文件后追加）：

- `index.html?sample=police` —— 冒充公检法
- `index.html?sample=service` —— 客服退款、扣费
- `index.html?sample=brush` —— 刷单返利
- `index.html?sample=boss` —— 冒充领导借钱
- `index.html?sample=link` —— 陌生链接领红包

### 放到手机上

把整个文件夹放到任意静态网站空间，用手机浏览器访问即可；支持“添加到主屏幕”，页面会以独立应用的样子打开。

PWA 离线缓存（Service Worker）只在 `http/https` 下启用；直接双击 `file://` 打开时，核心功能仍然可用，只是不注册离线缓存。

`file://` 下，浏览器的语音输入、剪贴板读取可能受权限限制。应用会给出“请长按输入框粘贴”“请用文字输入”等替代提示，不影响风险检查。

## 隐私

- **没有后端，没有账号，没有网络请求。**
- 消息只在当前页面内做规则匹配，不上传、不保存原文；
- 家人电话、家庭暗号、学习记录、字号设置保存在浏览器 `localStorage`（键名 `anxin.v1`）；
- 分享求助文字时，只有您主动点“复制”或“系统分享”，内容才会离开本机；
- 可在“守护 → 设置 → 清除本机数据”中一次性删掉全部记录。

---

## 识别能力与边界

引擎是**本地加权规则**，不是大模型，也不是官方判定：

- 27 条规则、6 个类别，带类别上限和关键信号；
- “安全账户”“索要验证码”“屏幕共享”“安装包”等会直接拉高等级；
- 能识别链接、短链接域名，并对“防骗宣传文字”做降级；
- 能区分“银行发来验证码”和“有人向你要验证码”；
- 对新的、改写过的骗术可能漏判，也可能误判。

因此：

> **它是提醒器，不是判决书。**

无论结果高低，只要涉及转账、验证码、屏幕共享，请先停下来。最可靠的做法始终是：

1. 挂断电话，不点链接，不装软件；
2. 用原来的号码回拨家人，或拨打 **96110** 核实；
3. 已经转账，立刻拨打 **110** 并联系银行。

本应用是公益科普演示，**不是官方应用**，不代表公安、银行或任何机构。

## 无障碍与适老化

- 三档字号，正文、按钮和底部导航一起放大；
- 主要点击区域 44–64px，减少误触；
- 高对比度配色、清晰的焦点样式；
- 结果区、冷静角使用 `aria-live`，状态变化可被读屏软件感知；
- 答题后有焦点管理，键盘和读屏用户不会“丢失位置”；
- 支持 `prefers-reduced-motion`，减少动效；
- 案例可朗读，适合视力不便的长辈。

## 测试

打开 `tests/engine.test.html`，会运行 17 条引擎断言，覆盖：

- 冒充公检法、客服、领导；
- 刷单、投资、陌生链接；
- 正常快递、家人消息、忘记密码；
- 防骗提醒、冒充反诈中心；
- 正常验证码短信与索要验证码的区分；
- 银行“请勿把验证码告诉他人”的安全提醒；
- 空输入。

当前结果：**PASS 17/17**。

开发时另用 Edge headless + Chrome DevTools Protocol 做过交互检查：390×844 与 320×700 两种视口、特大字号下无横向溢出、无 JS 报错；冷静角倒计时与答题、结果页、每日小测、家人联系人、暗号、分享弹窗均已走通。

规则测试只能说明这些样例符合预期，不代表对所有真实话术都能准确判断。
